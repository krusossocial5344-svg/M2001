# Social Quest ม.2

เว็บไซต์สไลด์ Interactive แบบ Static สำหรับ GitHub และ Vercel

## ใช้งาน
เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์หรือ deploy โฟลเดอร์นี้บน Vercel (Framework: Other; Build Command: เว้นว่าง; Output Directory: `.`)

## GitHub
`git init` → `git add .` → `git commit -m "Initial Social Quest"` → เชื่อม remote และ push แล้ว Import Repository ใน Vercel

## ความสามารถ
